# Interactive Portfolio Starter (Zero-Server & GitHub Pages Ready)

This folder works both by **double-clicking `index.html` directly** on your computer and when hosted live on **GitHub Pages**—no local server or terminal commands required.

## Folder Architecture

```text
portfolio-demo-v2/
├── index.html   # Double-click this file directly to open in any browser
├── style.css    # Full-viewport canvas layout & slide-over animations
├── data.js      # All your portfolio text, tags, and links in one place
├── app.js       # Event listeners and drawer rendering
└── README.md    # Setup & deployment guide
```

## Deploying to GitHub Pages

1. Push all files inside `portfolio-demo-v2/` to the root of a GitHub repository.
2. Go to **Settings → Pages** in your repository.
3. Under **Source**, select `Deploy from a branch`, choose `main` and `/ (root)`, and click **Save**.
